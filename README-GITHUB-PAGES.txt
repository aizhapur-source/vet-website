GITHUB PAGES QUICK START
1. Create a PUBLIC GitHub repository.
2. Upload everything in this folder to the repository ROOT.
3. Make sure index.html is directly in the repository root.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.

IMPORTANT:
This package contains the HTML pages and local breed illustration fallbacks.
The original animal JPEG photo folder was not included in the supplied ZIP,
so the website's original animal-photo references are preserved as supplied.
Breed pages will attempt to load breed-specific photos from Wikipedia/Wikimedia
when the visitor is online, with local illustrations as fallback.
